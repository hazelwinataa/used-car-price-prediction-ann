# Dataset access and provenance

The academic notebook originally loads a Parquet file named `1B.parquet`, containing 2,000 used-car records. The file is **not provided** in the materials available for this repository and must not be replaced silently with unrelated data. This folder intentionally contains no data rows. To rerun, restore a licensed copy of the original Parquet file in the working directory from which Jupyter is launched. The `.gitignore` excludes Parquet and other raw tabular datasets by default.

The source notebook includes original executed outputs and plots, but the training run has not been independently reexecuted in this package.
